Halo, saya Ikhsan, seorang Web Developer dan lulusan Informatika dari Universitas Komputer Indonesia (UNIKOM), Bandung.

Saya memiliki ketertarikan dalam pengembangan aplikasi berbasis web, mulai dari perancangan database, pengembangan backend, hingga membangun antarmuka yang responsif dan mudah digunakan. Saya terbiasa menggunakan Laravel dan berbagai teknologi web untuk mengembangkan aplikasi yang fungsional dan terstruktur.

Melalui portofolio ini, saya ingin menampilkan proyek-proyek yang telah saya kerjakan, kemampuan teknis, serta pengalaman saya dalam mengembangkan solusi digital. Saya juga terus belajar dan mengembangkan keterampilan untuk mengikuti perkembangan teknologi.
